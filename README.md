# AI Call Agent

AI агент, който звъни по телефона вместо теб: записва часове при лекар, за услуги и т.н., и говори на български. Контекстът на продукта и планът за MVP са в [CLAUDE.md](CLAUDE.md).

## Статус: MVP стъпка 1 (тест на гласа)

`backend/` е Node + TypeScript сървър с endpoint `POST /test-call`. Той звъни на твоя номер през Twilio и води кратък разговор на български с Claude, а ти играеш регистратурата. Целта е да проверим основния риск: доколко добре се разпознава и синтезира българска реч.

Как протича едно обаждане:

1. `POST /test-call` → Twilio набира `TEST_PHONE_NUMBER`.
2. Когато вдигнеш, агентът казва фиксиран встъпителен текст. В него задължително се представя като **AI асистент** и казва, че разговорът не се записва.
3. Twilio `<Gather input="speech" language="bg-BG">` разпознава какво казваш → `/twilio/gather` → Claude генерира отговора → Twilio `<Say>` го прочита с глас `Google.bg-BG-*`.
4. Агентът затваря, когато часът е договорен (инструмент `end_call`), след 3 поредни мълчания или след `AGENT_MAX_TURNS` реплики.
5. След края на разговора в конзолата се извежда целият транскрипт, заедно с confidence на разпознаването. Транскриптът се пази само в паметта и се изтрива веднага след това.

> За този тест разпознаването и синтезът на реч са на самия Twilio. Така сравняваме качеството на българската реч при най-простата схема. По-късно можем да преминем към Vapi, Retell или LiveKit (вж. CLAUDE.md) и да сравним.

## Setup

Изисквания: Node 20+, [Twilio](https://www.twilio.com) акаунт, [Anthropic API](https://platform.claude.com) ключ и [ngrok](https://ngrok.com) (или друг публичен HTTPS тунел).

1. **Twilio**
   - Създай акаунт и купи номер с Voice възможност.
   - При trial акаунт: в *Phone Numbers → Verified Caller IDs* потвърди своя български номер. Trial може да звъни само на потвърдени номера, а преди разговора пуска кратко съобщение.
   - В *Voice → Settings → Geo permissions* разреши обаждания към **Bulgaria**.
   - Запиши си Account SID и Auth Token от конзолата.
2. **Инсталация**
   ```bash
   cd backend
   npm install
   cp .env.example .env
   ```
3. **Тунел.** В отделен терминал пусни `ngrok http 3000` и сложи HTTPS адреса в `PUBLIC_BASE_URL`.
4. **Попълни `.env`.** Сложи Twilio данните, `TEST_PHONE_NUMBER` (твоя номер, напр. `+359888123456`), `ANTHROPIC_API_KEY` и `TEST_CALL_TOKEN`, който можеш да генерираш с `openssl rand -hex 32`.
5. **Стартирай**
   ```bash
   npm run dev
   ```
6. **Звънни**
   ```bash
   curl -X POST http://localhost:3000/test-call \
     -H "Authorization: Bearer $TEST_CALL_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"task": "Запиши час при уролог в Токуда. Свободен е вторник до четвъртък след 14:00."}'
   ```
   `task` не е задължителен. Ако липсва, се използва `AGENT_DEFAULT_TASK`.

## Сигурност

- Всички ключове се пазят само в `.env`, който е в `.gitignore`.
- `POST /test-call` изисква `Authorization: Bearer <TEST_CALL_TOKEN>`, иначе всеки с адреса на тунела би могъл да пуска обаждания за твоя сметка.
- Webhook-овете от Twilio се проверяват по `X-Twilio-Signature`.
- Агентът няма да каже ЕГН, направление или здравни данни, а в тази стъпка изобщо не ги получава.

## Какво да тестваш

Опитай бърз говор, говор с шум около теб, имена на лекари, часове („в три и половина“, „петнайсет и трийсет“) и дати. След всеки разговор гледай транскрипта и confidence в конзолата. Сравни и гласовете `Google.bg-BG-Standard-A` и `-B` (`TTS_VOICE`), както и различни `STT_SPEECH_MODEL`.
