# AI Call Agent

## Продукт
Мобилно приложение, в което AI агент прави телефонни обаждания вместо потребителя: записване на часове при лекар, услуги, абонаменти и др. Пример: "Запиши ме при уролог в Токуда, свободен съм вт–чт след 14:00" → агентът звъни, договаря час, проверява календара и връща "Записан си вторник 15:00, без конфликти".

## Уникално предимство
- Агентът звъни реално и води разговора на български.
- Проверява календара на потребителя по време на разговора.
- Когато предложат час, потребителят получава push известие и одобрява или отказва.
- Чувствителни данни (ЕГН, направление) се казват само след изрично одобрение.

## Архитектура
- Mobile: React Native + Expo + TypeScript. Въвеждане на задача, транскрипция на живо, одобрения, достъп до календара.
- Backend: Node + TypeScript. Изходящи обаждания през Twilio.
- Глас: реч→текст → Claude API → текст→реч. Текущо: Twilio ConversationRelay (поточно, с прекъсване) + Claude. Алтернативи за сравнение: Vapi, Retell, LiveKit Agents.
- Инструменти на агента по време на разговор: check_calendar, request_user_approval, end_call, save_result.

## Задължителни изисквания
- В началото на всеки разговор агентът казва, че е AI асистент (EU AI Act).
- Съгласие за запис на разговора.
- Здравните данни се третират по GDPR: минимално съхранение, криптиране.
- Всички ключове се пазят в .env, никога в кода.

## Основен риск
Качеството на българската реч (разпознаване и синтез) при бърз говор и лоша линия. Тестваме го преди всичко останало.

## План за MVP
1. Агентът звъни на моя номер и води кратък разговор на български, като аз играя регистратурата.
2. Проверка на календара + одобрение с push + запис на събитието.
3. Реално обаждане до клиника.
